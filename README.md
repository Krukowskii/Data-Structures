# 🧩 Custom Data Structures

A collection of my own implementations of fundamental data structures such as vectors, maps, sets, and more — all written from scratch to deepen my understanding of algorithms, memory management, and C++ internals.

---

## 🚀 Features
- `Vector` — dynamic array implementation (similar to `std::vector`)
- Planned: `Map`, `Set`, `Queue`, `Stack`, `LinkedList`, `Tree`, `HashMap`

---

## 💡 Motivation
This repository is part of my learning journey in computer science.  
I'm recreating well-known data structures to understand how they work under the hood and to improve my C++ design and optimization skills.
